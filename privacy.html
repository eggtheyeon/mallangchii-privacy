개인정보처리방침

시행일: 2026년 10월 18일

말랑치이 업로드 도구(Google OAuth 앱 'autoFunny', 이하 '도구')는 유튜브 채널 말랑치이의 운영자가 본인 채널을 관리하려고 만든 개인용 프로그램입니다.

1. 사용하는 정보

도구는 Google 로그인 때 운영자가 허락한 범위 안에서 운영자 본인의 유튜브 계정에만 접근합니다.

  • 영상 업로드와 공개 예약(YouTube Data API: youtube.upload)
  • 올린 영상의 처리·공개·차단 상태 조회(youtube.readonly)
  • 채널 조회수 통계 조회(yt-analytics.readonly)
  • 본인이 올린 영상의 공개 상태 변경(예약 취소·비공개 전환, youtube.force-ssl)

2. 보관과 공유

  • 로그인 토큰과 조회 결과는 운영자의 개인 컴퓨터에만 저장하며 외부 서버로 보내지 않습니다.
  • 어떤 정보도 제3자에게 팔거나 넘기지 않고, 광고에 쓰지 않습니다.
  • 다른 사용자의 계정 정보는 받지 않습니다.

3. Google API 서비스 사용자 데이터 정책

도구가 Google API로 받은 정보의 사용과 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

4. 권한 철회와 삭제

Google 계정의 서드 파티 연결에서 언제든 도구의 접근 권한을 철회할 수 있습니다. 철회하면 저장된 토큰은 더 이상 쓸 수 없으며, 운영자는 컴퓨터에 남은 토큰 파일을 지웁니다.
